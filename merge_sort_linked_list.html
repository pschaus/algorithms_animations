Why Merge Sort for Linked Lists? LINFO1121 Invariants

Sequential Access Only: Unlike arrays, singly linked lists lack $O(1)$ random indexing. Merge Sort operates strictly sequentially, making it asymptotically optimal ($\Theta(N \log N)$).

$O(1)$ Auxiliary Heap Memory: In array merge sort, an auxiliary array aux[N] is required ($O(N)$ space). For linked lists, merging is done in-place by pointer rewiring (adjusting .next references) without allocating new nodes!

Stable Sorting: The condition a.val <= b.val ensures that whenever keys are equal, the element from the left sublist is merged first, strictly preserving initial relative order.
