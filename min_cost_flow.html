Successive Shortest Path Algorithm P. Schaus / Ahuja et al.
double totalCost = 0.0, vFlow = 0.0; while (vFlow < B) {   // Find shortest path in G_f with respect to costs a_f (Bellman-Ford)   Path P = bellmanFordShortestPath(G_f, s, t, a_f);   if (P == null) return INFEASIBLE;   // Bottleneck capacity: min(remaining demand, min c_f(e))   double delta = Math.min(B - vFlow, P.bottleneck());   // Augment flow (forward adds cost, backward refunds cost!)   augmentFlow(P, delta);   vFlow += delta;   totalCost += delta * P.unitCost(); } return totalCost; // Optimal Minimum-Cost Flow
