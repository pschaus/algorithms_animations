Binary Search Analysis & Invariants LINFO1121 Invariants

Logarithmic Guarantee: Because the remaining search interval is divided in half at each iteration, the maximum number of iterations is $\lfloor \log_2 N \rfloor + 1$. For $N = 1\,000\,000$, at most 20 comparisons are ever needed!

Integer Overflow Bug Avoidance: Writing low + (high - low) / 2 instead of (low + high) / 2 avoids arithmetic overflow when low + high exceeds $2^{31}-1$ (a famous bug that stayed hidden in Java for 9 years!).

Negative Return Value: -(low + 1) When key is not found, low is the exact insertion point where key should be inserted to keep the array sorted. Java returns -(low + 1) instead of -low because if low == 0, -0 == 0, which would collide with a match at index 0! The insertion point is recovered as: insertion_point = -result - 1.
