Data Structure Invariants

1. Equal Parallel Sizes: After every put, keys, values, idxLeftNode, and idxRightNode have the exact same size $N$. The $i$-th inserted distinct key always resides at index $i$.

2. Pre-Linking Leaf Reference: When reaching next == NONE (-1) at node $i$, idxChild.set(i, keys.size()) stores the future child index $N$ before addNode(key, val) appends the new node at index $N$.
