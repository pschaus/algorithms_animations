Invariants & Cycle Detection Union-Find Cycle Check

Cut Property: The minimum-weight edge crossing any cut separating two sets of vertices must belong to the Minimum Spanning Tree (MST).

Cycle Detection: If find(u) == find(v), the vertices already share the same root and are already connected. The edge is rejected to avoid forming a cycle.

Complexity $O(E \log E)$: Initial sorting of the $E$ edges dominates the runtime. Cycle checks via Union-Find (WQUPC) take nearly linear time $O(E \alpha(V))$.
