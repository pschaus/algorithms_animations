Memory & Stability Invariants LINFO1121 Key Concepts

Heap Allocation vs Shared Buffer: In Version 1, allocating new int[mid] and new int[len-mid] inside every recursive call creates $O(N \log N)$ total allocated integers on the Java heap, causing high garbage collection pressure. In Version 2 (Sedgewick), allocating a single shared int[] aux = new int[N] upfront reuses the same memory buffer across all recursive levels with zero reallocation overhead.

Common Exam Trap: Allocating aux = new int[hi - lo + 1] or aux = new int[N] inside the merge() function is a severe mistake! It combines the overhead of repeated allocations with the complexity of index offsets.

Stability Invariant: Merge Sort is stable if and only if equal elements from the left subarray are merged before equal elements from the right subarray.
Notice: In left[leftIndex] < right[rightIndex], ties fall into else, taking the right element first and inverting stability! Use ≤ to preserve stability.
