Radix Sort Invariants

Stability is Essential: Key-indexed counting must be stable so that when sorting on digit $d$, keys with identical $d$-th character remain sorted by digit $d+1 \dots W-1$.

Linear Time: Runtime is $O(W(N + R))$, requiring $W$ passes. Linear in the size of input for small radices.
