Theoretical Guarantees

Time Complexity: $O(E \log V)$ using an Index Min-PQ. Each vertex is deleted from PQ once, and each directed edge is relaxed at most once.

Non-Negative Weights: Requires $w \ge 0$. If negative edge weights exist, Bellman-Ford algorithm must be used.
