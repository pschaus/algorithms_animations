Invariants & Number of Inversions LINFO1121 Invariants

Loop Invariant: At the start of outer loop iteration i, the prefix subarray arr[0..i-1] is guaranteed to be fully sorted!

Inversions & Shifts: An inversion is a pair of indices $(p, q)$ such that $p < q$ and $arr[p] > arr[q]$. Each right-shift arr[j+1] = arr[j] eliminates exactly 1 inversion. The total number of shifts equals the exact number of inversions in the input!

Adaptive Complexity: Best case (already sorted array): only $N-1$ comparisons, $0$ shifts $\implies \mathbf{O(N)}$ linear time! Worst case (reversed array): $N(N-1)/2$ comparisons and shifts $\implies \mathbf{\Theta(N^2)}$ quadratic time.

Strict Stability: Because the inner while loop checks arr[j] > key (strict inequality), shifting halts as soon as an equal key is encountered. Thus, equal keys retain their original relative order.
